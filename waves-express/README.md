# Waves Express

MVP do canal de compra assistida Waves Plus.

## Direção visual
- Hero forte, inspirado em landing pages premium, mas com linguagem de oficina moderna.
- Azul petróleo/navy + laranja como eixos principais, amarelo Waves apenas como assinatura/acento.
- Visual humanizado: pessoas em situação real de oficina, serralheria, manutenção e obra; evitar poses de banco de imagem.
- Produto sempre grande, limpo e reconhecível.
- Tipografia condensada de impacto nos títulos + sans limpa nos textos.

## Página de produto
- Galeria de fotos em **rolagem vertical** (puxar para cima), nunca carrossel horizontal.
- Slide final reservado para vídeo/demonstração do produto.
- Informações e CTA ficam estáveis enquanto a mídia sobe no desktop.
- No mobile, CTA de WhatsApp permanece fixo no rodapé.

## Dados
Os 20 primeiros produtos foram estruturados com códigos, composição e descrições iniciais. Os valores públicos do Waves Express ficam separados dos benchmarks Clássico/Premium.
